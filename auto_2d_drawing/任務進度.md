# 自動 2D 工程圖繪製系統 — 任務進度追蹤

> **專案目標**：讀取 3D STEP 模型 → 自動產生符合 FORCECON 力致科技標準的 2D 工程圖 (DXF/PDF)
> **測試模型**：BLADE_ASSY-1AC085000H-R01.stp
> **建立日期**：2026-05-22

---

## 動作流程總覽

```mermaid
graph TD
    A[STEP 3D 模型] --> B[python-occ 讀取與分析]
    B --> C[提取幾何特徵]
    C --> C1[Bounding Box 外觀尺寸]
    C --> C2[圓柱面 → 孔洞/軸識別]
    C --> C3[圓弧邊 → R 半徑]
    C --> C4[階梯面 → 段差尺寸]
    B --> D[HLR 三視圖投影]
    D --> D1[前視圖 Front]
    D --> D2[俯視圖 Top]
    D --> D3[右側視圖 Right]
    D1 --> E[ezdxf 繪製 DXF]
    D2 --> E
    D3 --> E
    C1 --> F[自動尺寸標註引擎]
    C2 --> F
    C3 --> F
    C4 --> F
    F --> E
    E --> G[繪製圖框 + 標題欄]
    G --> H[輸出 DXF]
    G --> I[輸出 PDF]
```

## 備註

- python-occ 負責所有 3D 幾何運算 (讀檔、HLR 投影、特徵提取)
- ezdxf 負責所有 2D 圖面繪製 (DXF 生成、標註、圖框)
- 兩者都需要 `pyoccenv` conda 環境來運行
- 先以 BLADE_ASSY 進行原型開發，確認流程正確後再擴展至其他零件
